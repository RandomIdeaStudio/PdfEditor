## 1. License and legal
- [x] `LICENSE` (MIT), copyright © 2026 Random Idea Studio
- [x] `THIRD_PARTY_NOTICES.md` and About dialog list every bundled component and its license (all OSI-approved, no AGPL)
- [x] Icon is generated by `assets/generate_icon.py` (own work)

## 2. Privacy
- [x] `PRIVACY.md` in English and Czech, public in the repository
- [x] The program makes no network connections (no telemetry, no crash reporting)
- [x] About dialog states the privacy promise (`about.privacy`)

## 3. Code and build
- [x] `.\scripts\test.ps1` green
- [x] Version only in `src/pdf_editor/__init__.py` and `assets/version_info.txt` (build fails if they differ), `CHANGELOG.md` matches
- [x] `.\scripts\build.ps1` from a clean checkout of `main` produces `dist\PdfEditor_Setup_v<version>.exe` and its `.sha256`
- [x] No builds committed (`dist/`, `build/`, `*.exe` ignored)
- [ ] Git tag `vX.Y.Z` on `main`

## 4. Manual smoke test of the built executable
- [ ] Starts on a machine without Python, opens a PDF, saves edits
- [ ] Redaction removes the underlying text (cannot be selected or copied)
- [ ] Install from the setup window, right-click entries work, uninstall removes them and the Installed apps entry
- [ ] Czech and English UI

## 5. Code signing (from the first signed release)
- [ ] Built in GitHub Actions (`ci.yml` with `build_exe` and `sign`), signing request approved in SignPath
- [ ] Signature verified (`Get-AuthenticodeSignature`)
- N/A for 1.0.0: released unsigned, because SignPath Foundation only accepts projects that are already released

## 6. Publishing
- [ ] GitHub Release with the executable, the `.sha256` file and release notes from `CHANGELOG.md`
- [ ] Website project entry links to the latest release, the code signing policy and the privacy policy
